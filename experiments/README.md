# Experiments

Organized as a chronological narrative, one numbered folder per stage.
Start at `00_infrastructure/README.md` for reused components, then follow
`01_direct_rl_coinflip/` → `06_stage4_coinflip_merge/` in order. Each stage
folder's `README.md` follows the same template: what we tried, why, key
steps/iterations, final result, what it meant for the next step.
Superseded/one-off material lives in `archive/`, out of the main sequence.

Full chronological detail, including everything not compressed into the
per-stage summaries, is in `../logs/development_log.md`.

(This replaces an earlier `YYYY-MM-DD_short-description/` +
`config.yaml`/`notes.md` convention documented here previously, which was
never actually followed by any experiment in this repo.)
